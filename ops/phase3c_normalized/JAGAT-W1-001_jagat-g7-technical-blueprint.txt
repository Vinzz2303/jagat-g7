1. RINGKASAN EKSEKUTIF & MANIFESTO GARUDA 7
1.1 Latar Belakang Strategis
Dalam lanskap geopolitik digital kontemporer, ketergantungan terhadap infrastruktur kecerdasan buatan milik
korporasi asing merepresentasikan sebuah kerentanan kedaulatan data (data sovereignty vulnerability) yang
bersifat eksistensial. Setiap kueri yang dikirim ke endpoint API komersial — baik itu OpenAI, Anthropic, maupun
Google — secara inheren menyerahkan kontrol atas aliran data, latensi inferensi, kebijakan retensi, dan
determinisme biaya kepada entitas di luar yurisdiksi nasional.
JAGAT G7 (Garuda 7) lahir sebagai respons arsitektural terhadap realitas ini. Platform ini bukan sekadar
antarmuka pengguna yang membungkus API pihak ketiga (API wrapper), bukan pula sebuah chatbot scaffold yang
meneruskan prompt ke satu model tunggal. JAGAT G7 adalah sebuah Mesin Sintesis Kognitif Multi-Model
Berdaulat (Sovereign Multi-Model Cognitive Synthesis Engine) — sebuah sistem yang secara fundamental
merancang ulang bagaimana kecerdasan buatan dikonsumsi, diorkestrasi, dan dikendalikan dari titik kontrol lokal
yang sepenuhnya berada di bawah otoritas operator.
1.2 Filosofi Nomenklatur: Mengapa "G7"
Penamaan Garuda 7 membawa dua dimensi simbolik yang saling memperkuat:
G — GARUDA
Garuda merepresentasikan kedaulatan digital absolut (absolute digital sovereignty). Sebagaimana Garuda
Pancasila menjadi lambang negara yang menjaga integritas bangsa, JAGAT Garuda menjadi penjaga integritas
data dan inferensi AI nasional. Garuda terbang di atas awan — bukan bergantung padanya. Filosofi ini secara
langsung menantang paradigma cloud-first yang telah mendominasi industri selama satu dekade terakhir, dan
menggantinya dengan paradigma bare-metal sovereignty: infrastruktur berjalan di atas besi yang kita miliki, di
tanah yang kita kuasai.

7 — TUJUH APEX MINDS (Tujuh Pikiran Puncak)
Angka 7 merepresentasikan visi inti dari arsitektur kognitif JAGAT: mensintesis dan mengagregasi kapabilitas
penalaran, kreativitas, dan keahlian spesifik dari 7 raksasa AI global ke dalam SATU mesin inferensi

# APEX MIND KAPABILITAS INTI YANG DIEKSTRAKSI
1 Claude (Anthropic) Penalaran mendalam, analisis kontekstual panjang, kepatuhan instruksional
2 GPT (OpenAI) Generasi teks serbaguna, kreativitas naratif, pemrosesan multimodal
3 Gemini (Google DeepMind) Penalaran multimodal, integrasi pengetahuan real-time, kapasitas konteks

4 Groq (Groq Inc.) Inferensi ultra-rendah-latensi, throughput token per detik tertinggi
5 Mistral (Mistral AI) Efisiensi parameter, penalaran terstruktur, keunggulan pada model kompak
6 Llama (Meta AI) Fondasi open-weight, fine-tuning tanpa batas, kontrol penuh atas bobot model

PENTING
Konsep "7 Pikiran → 1 Otak" bukan berarti menjalankan 7 API secara paralel. Ini adalah proses distilasi
kognitif (cognitive distillation): mempelajari reasoning patterns, prompt engineering strategies, dan domain-
specific strengths dari masing-masing model, lalu menanamkannya ke dalam satu pipeline inferensi lokal
yang berjalan di atas Llama 3 sebagai base cognitive worker — diperkaya dengan system prompts yang
telah di-engineer untuk mereplikasi kekuatan gabungan ketujuh model tersebut.

3. DEEP-DIVE: LAPISAN ORKESTRASI BFF (BACKEND-FOR-
FRONTEND)
3.1 Apa Itu Pola BFF dan Mengapa JAGAT Mengadopsinya
Pola Backend-For-Frontend (BFF) adalah sebuah paradigma arsitektural di mana sebuah server backend
dibangun secara spesifik dan eksklusif untuk melayani kebutuhan satu frontend tertentu. Dalam konteks JAGAT
G7, Express.js engine pada Port 5000 tidak dimaksudkan sebagai API publik yang bisa dikonsumsi oleh
sembarang klien — ia adalah pelayan eksklusif (dedicated servant) dari antarmuka Next.js pada Port 50012.
Mengapa Ini Kritis untuk Kedaulatan:
Shielding Infrastruktur Internal: Klien publik tidak pernah mengetahui keberadaan Redis, Qdrant, maupun
Ollama. Mereka hanya melihat satu endpoint: BFF pada Port 5000. Ini menciptakan information asymmetry
yang melindungi topologi internal dari reconnaissance.
Sanitasi & Agregasi Data: Sebelum respons dikirim ke frontend, BFF melakukan validasi input, agregasi multi-
sumber (embedding → vector search → LLM inference), format normalisasi, dan metrics injection.
Pencegahan Kebocoran Data: Semua error internal di-wrap di lapisan BFF. Pada mode produksi, pesan error
asli tidak pernah terekspos — hanya generic "An unexpected error occurred" yang dikirim ke klien.

4. PETA JALAN STRATEGIS — 5 FASE EVOLUSI GARUDA 7
FASE 1: FONDASI & IGNISI KEDAULATAN (SOVEREIGN IGNITION)
Status: ██████████████████████ 100% SELESAI ✅
Fase ini merepresentasikan migrasi total dari paradigma cloud-dependent ke arsitektur bare-metal sovereign.
Seluruh komponen infrastruktur telah diinstalasi, dikonfigurasi, dan diverifikasi berjalan secara native di atas
dedicated server tanpa layer virtualisasi maupun kontainerisasi.
Patch Infrastruktur Kritis — Catatan Rekayasa Lapangan
Selama proses ignisi kedaulatan, dua anomali teknis fundamental ditemukan dan diperbaiki pada runtime Node.js
v26 yang masih sangat baru:
🔧 PATCH #1: Redis Singleton — Reuse Koneksi LazyConnect (`redis.service.ts`)
Akar Masalah: Library `ioredis` melemparkan exception pada endpoint `/health` karena memanggil `connect()`
berulang kali pada singleton client yang sudah aktif ("ready"). Solusinya adalah menyuntikkan status guard:
// Only call connect() if not already connected (lazyConnect singleton)
if (redis.status === "wait" || redis.status === "end") {
await redis.connect();
}
🔧 PATCH #2: Qdrant Client — Konflik Undici pada Node v26 (`qdrant.service.ts`)
Akar Masalah: Library `@qdrant/js-client-rest` mem-bundle `undici` sendiri yang bentrok dengan native
implementation Node v26. Solusinya adalah menonaktifkan `checkCompatibility: false` dan mengganti mekanisme
ping SDK dengan Native Fetch langsung ke endpoint server.
FASE 2: PROTOKOL SINTESIS & INJEKSI PROMPT KOGNITIF
Status: Target Q2 2026 🔄 (In Progress)
Visi fase ini adalah merancang instruksi sistem (system prompt) berlapis yang memaksa mesin lokal mengadopsi
struktur logika terbaik dari GPT-4, Claude 3.5, dan Gemini Pro secara simultan sebagai basis pilar kognitif utama
GARUDA 7.
FASE 3: INGESTI DATA MASSAL & TUNING RETRIEVAL HIBRIDA
Status: Target Q3 2026 📋 (Planned)
