# Aturan Proyek Bapenda (Project-Scoped Rules)

Proyek ini adalah prototipe Dashboard Enterprise serius. Aturan berikut wajib dipatuhi:

## 1. Integrasi UI/UX Promax
Aplikasi ini wajib menggunakan standar desain "UI/UX Promax" yang bersih dan minimalis (Anti "AI Slop"). Gunakan estetika desain ala Linear/Stripe.

## 2. Struktur Komponen React
Pecah komponen menjadi sekecil mungkin. Semua komponen baru harus menggunakan TypeScript (`.tsx`) dan dipisahkan di bawah direktori `src/components/`.

## 3. Eksekusi Perintah
Saat membuat modifikasi, pastikan semua import dan dependencies dikelola dengan baik. Gunakan Tailwind v4 (via `@tailwindcss/vite`).
