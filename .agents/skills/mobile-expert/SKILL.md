# Mobile Expert Skill

1. **Collapsible Navigations**: Sidebars MUST convert to a hamburger menu or bottom navigation bar on screens `< md` (768px).
2. **Layout Shifting**: Grids (`grid-cols-X`) must gracefully degrade to `grid-cols-1` on mobile.
3. **Touch Targets**: Buttons and interactive elements should have adequate padding (min 44px height equivalent) for finger taps.
4. **Overflow Handling**: Tables must have horizontal scroll wrappers (`overflow-x-auto`) to prevent breaking layouts on small screens.
