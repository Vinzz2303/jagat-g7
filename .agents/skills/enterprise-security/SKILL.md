# Enterprise Security Skill

When building authentication or security-related components:
1. **Trust-Inducing UI**: Use very clean, minimal layouts (e.g., Stripe login). Centered white cards on a light gray background (`bg-gray-50`).
2. **Micro-copy**: Include trust signals (e.g., "Secured by AI Tax Center 256-bit encryption", official Bapenda logos).
3. **Smooth Transitions**: Use `framer-motion` to transition between login steps (e.g., sliding from password input to 2FA PIN code).
