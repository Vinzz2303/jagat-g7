# UI/UX Promax (Enterprise Design Skill)

When invoked or working on frontend tasks in this workspace, apply the following design standards:

1. **Aesthetics over Fluff**: Prioritize a clean, minimalist, and highly functional aesthetic similar to Stripe, Linear, or Tailwind UI.
2. **Colors**:
   - Use clean, low-saturation backgrounds (e.g., `#f9fafb`, `#ffffff`).
   - Avoid neon, harsh gradients, and heavy glassmorphism.
   - Use muted, highly legible colors for accents (e.g., emerald for success, rose for error).
3. **Typography**:
   - Use a modern sans-serif font (Inter, Roboto, SF Pro).
   - Implement strict typographic hierarchy (tight tracking on headers, subdued grays for subtext).
4. **Borders & Shadows**:
   - Use subtle 1px borders (`border-gray-200`) and micro-shadows (`shadow-sm`) instead of floating elements.
5. **Data Presentation**:
   - Favor clean data tables, elegant activity feeds, and muted charts over "hacker terminals" or overly complex dashboard widgets.
